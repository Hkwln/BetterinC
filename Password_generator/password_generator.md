# PASSWORD_GENERATOR:

Aim for this is to advance a simple basic password generator i coded a few years ago to the latest standards

## Features:

- Pronouncable password option, currenty German style
  - password safety indicator
- in dev phase:
  - pleasing ui - not just simple Tui print and scan statements
  - multiple password generaton
  - modern random algorithm using csprng with the help of sha256
- lighning fast with pure C

All done by myself - no code written by Ai - because it is fun to code :)
