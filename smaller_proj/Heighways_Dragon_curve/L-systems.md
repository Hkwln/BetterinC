# Lindenmann-Systems

## L-system vs chomsky

### chomsky

- aim: generates a language, question: is this specific language valid in this language
- production is applied sequentially
- non-terminals _must_ be replaced by terminals, derivative ends when all symbols are terminals
- you choose one non-terminal and one production rule

### l-system

- aim: development process, don't care if its valid, care about the evolution
- production is applied in parallel
- you never "finish" rewriting, you stop after a set number of iterations.
